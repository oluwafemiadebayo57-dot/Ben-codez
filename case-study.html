Overview

What is Bencodez-Ventures?

Bencodez-Ventures is a multi-category online store selling everything from clothes and gadgets to cosmetics, deodorants, and jewellery. The business owner needed a way to list products, receive orders, and manage inventory — without relying on expensive third-party platforms.

I designed and built the entire platform from the ground up: a secure REST API, a PostgreSQL database, a customer-facing storefront, and a full admin dashboard for managing the business.

Challenges & Solutions

What I learned building it

Migrating from local PostgreSQL to Supabase

Moving the database to the cloud meant my backend could be deployed and reachable from anywhere. The tricky part was adapting connection details, setting up environment variables in Render, and re-running the schema in a fresh cloud instance — plus understanding that the connection uses a pooler URL for IPv4 compatibility.

Persistent image storage on ephemeral hosting

Render's free tier wipes disk on every deploy — so images saved locally would disappear. I migrated image uploads to Supabase Storage, so every uploaded product image gets a permanent CDN-backed public URL.

Avoiding stale data with async script order

The header renders dynamically, which means the cart badge element doesn't exist at the exact moment the page's inline script runs. I fixed this by guarding DOM updates with null checks and loading `config.js` before dependent scripts.

Secure by default — every layer

Parameterized SQL queries prevent injection. JWT protects every authenticated route. Helmet sets secure HTTP headers. Joi validates every request body. bcrypt hashes passwords. Rate limiting blocks brute-force attempts. Every layer assumes the request is untrusted until proven otherwise.
